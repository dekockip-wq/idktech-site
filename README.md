# idktech.co.za

The IDK Tech website. A static site served by GitHub Pages from the `main` branch root.

- One HTML file per page: `index.html` (home), `farm-sentinel.html`, `stockfox.html`, `solar.html`,
  `volttrack.html`, `ai-advisers.html`, `work.html`, `about.html`, `contact.html`, `404.html`
- `style.css`, `app.js`: shared by every page
- The header and footer are repeated in every page; change them in all of them together
- Every text has an English and an Afrikaans version side by side (`class="en"` / `class="af"`)
- `CNAME`: the custom domain (idktech.co.za)
- Form and booking settings live in the `CONFIG` block at the top of `app.js`
